# Max’s Learning Lab · Explorer Edition

A personal learning website made for touch, curiosity, and little discoveries.

- Five featured destinations and 50 surprise places, with bundled photographs.
- An interactive world map with family stops, zoom, and place search.
- An explorer passport that remembers discoveries on this device.
- Home Run Hero baseball, Block Lab, Pattern Studio, and Ocean Detective.
- Four Big Ideas profiles: Einstein, Katherine Johnson, Cousteau, and Frida Kahlo.
- Short facts, read-aloud buttons, gentle quizzes, and optional stretch questions.

**Start with [START-HERE.md](START-HERE.md)** for step-by-step GitHub Pages setup, iPad instructions, and how to add content.

There is no installation or build step. Upload the extracted files and folders together, keeping `index.html` at the repository’s top level. Do not upload just the ZIP.

Content lives in `data/`. Use `CONTENT-TEMPLATE.txt` when adding a new destination. Photo licenses and research sources are in `credits.html`.

Browser checks covered tablet portrait/landscape layouts, touch input, navigation, all 59 photo files, and the 50-place surprise cycle. Games received scoring, controls, and reset checks. This does not replace a tryout on your actual iPad; voice availability and Home Screen behavior depend on the device.
